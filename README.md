# Momentum Fitness

A responsive Nuxt 4 fitness-coaching concept with glassmorphic program cards, discovery-call booking, available time slots, and a member progress dashboard. REST endpoints support optional PostgreSQL persistence and fall back to demo data when no database is configured.

## Start
```bash
npm install
npm run dev
```

## Optional database
Copy `.env.example` to `.env`, set `DATABASE_URL`, and run `database/schema.sql` against PostgreSQL.

## Build
```bash
npm run build
npm run preview
```

All testimonials, member data, and metrics are clearly presented as portfolio sample content. This demo does not provide medical advice.
